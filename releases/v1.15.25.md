# v1.15.25 — companion multi-step chat + hazard index

**Feature (@feature).** Companion chat templates now emit real multi-step plans via
`enqueueChain`; world index reports nearby hazards for the model driver.

## Summary

- **Verdict:** Companion QoL — no native rebuild, no save-format change.
- **Scope:** `scripts/lua/rpg_plugins/companion.lua` + `scripts/lua/rpg.lua` changelog only.
- **Behaviour delta:** Enter-chat phrases like "cut the trees", "dig a hole", and "build a
  house" start chained tasks; `refreshIndex` adds `hazards` (LAVA/FIRE/ACID/PLSM); `buildRoom`
  refuses if the player stands inside the footprint; dig/build tasks speak start + halfway lines.
- **Risk:** low — new chat intents only run when the player asks; scripted brain still thin.

1. HUD shows v1.15.25 or newer.
2. Chat companion: "cut the trees" → colonist starts `clearTrees` chain.
