# Release v1.15.3 — emergency mouse-unstuck hotkey

**TL;DR — if a held-click bug ever leaves you stuck placing blocks or using tools with no way
out short of restarting, press **F11** and everything clears. No save, no quit, no reload.**

## What's in this release

A single, surgical addition: a new `R.releaseMouse()` function wired to the **F11** hotkey,
bridged as a Lua-callable on `R` so a plugin can call it programmatically as well as the
player hitting the key. Pressing F11 clears every transient mouse / placement flag the
engine holds — `R.mouse.l`, `R.mouse.r`, `R.placeBox`, `R.placeAnchor`, `R.zoomClick`,
`R.zoomPending`, `R.lastPlace`, `R.lastMine`, and `R.lineAnchor` if any of those are set —
so a held-click bug that somehow slips past `onMouseUp`'s reset can be killed without
restarting the game or losing the world.

## Why this exists

The mouse-held-down bug class keeps showing up in different shapes. v1.15.1 already moved
`onMouseUp`'s button-state reset ahead of every early-return path, and added a real
SDL-window-focus release at the engine level — but a future regression, or a new code path
added by a plugin that doesn't know to call into the same reset, can still leave `R.mouse.l`
or `R.mouse.r` latched with no recovery. F11 is the escape hatch. It's deliberately hard to
hit accidentally, deliberately a no-op when nothing is stuck, and deliberately clears every
flag at once so the player doesn't have to know which one of the eight internal flags is
the one that's stuck.

## How to verify

1. Start any session.
2. Press **F11** in a normal, not-stuck state — nothing should change; you're already fine.
3. *(Reproduction of a stuck case requires the pre-fix bug, which v1.15.1 already handled.)*
4. Bridge-verified live against the user's session by `@bugs`: `R.releaseMouse()` reads as
   defined on `R` after the `R.VERSION` bump to `1.15.3`, and the hotkey path is wired.

## What's NOT in this release

No new content, no balance changes, no physics tuning. Pure emergency-recovery addition so
a regression in any future release can't leave a player stuck mid-session. If F11 actually
fires for you on a real, current build, please open an issue with what you were doing right
before — that's a bug in some new state flag we should also clear, not a bug in the hotkey.
