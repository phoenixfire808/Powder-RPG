# Release v1.15.6 — version readout now in the always-on HUD

## Summary

The build's version string used to be readable from exactly two places: the title screen at
launch and the per-update "What's New" popup the first time it fires — both of which close
themselves once you're in a session. If you wanted to confirm mid-session that you were
running the build you thought you were (debugging a fresh bug, sanity-checking after a
hot-reload, comparing against a release post), the only path was Esc → some submenu item,
and there was no "version" row there either. v1.15.6 wires the version directly into the
always-on HUD, top-right corner, just above the Deaths counter. No menu dive, no popup
race — a real number you can read at a glance any time you're holding the game open.

## Changes

- **In-game version readout** is now shown in the always-on HUD, top-right, above the
  Deaths counter. Was only visible on the title screen and during the What's-New popup —
  mid-session builds no longer need to be checked via Esc menu or guessed.

## Affected files

- `scripts/lua/rpg.lua` — added the version readout to the always-on HUD draw loop
  (top-right corner, sitting above the existing Deaths-counter line that v1.15.5 added).
  No plugin changes needed; the HUD is the canonical place every other top-right readout
  lives, and the `R.VERSION` constant the title screen was already reading is the source
  of truth here too, so no new state to track.

## Migration notes

None. Pure QoL / visibility improvement. No save-format change, no behavior change, no
config change, no breaking change for plugins. `R.VERSION` continues to be the source of
truth — this just makes the in-game view of it match the title-screen view that already
worked.

## How to verify

1. Build or update to v1.15.6.
2. Start a world (or load an existing one — either works, the always-on HUD draws the
   same in both).
3. Look at the top-right corner of the screen.
4. The version string (e.g. `v1.15.6`) should be sitting just above the Deaths line that
   v1.15.5 added (which is only visible once you've actually died at least once).
5. Confirm the same string matches what you expect: same as the title screen at launch
   (that title-screen readout continues to work unchanged, since both read the same
   `R.VERSION` source), and same as the in-game "What's New" popup header.
6. Sanity check: hot-reload (F9, if a dev is running) flips the readout to whichever
   `R.VERSION` the freshly-loaded rpg.lua defines — confirming the HUD reads the live
   value rather than caching it once at start.
